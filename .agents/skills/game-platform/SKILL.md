---
name: game-platform
description: Prepare, build and verify a Haskell game's requested desktop, browser, server or mobile host, dependencies, assets and distribution without substituting an easier platform.
---

Read [current platform evidence](../../../docs/platforms.md),
[packaging practice](../../../docs/practice/games/stack.md), and for browser work
[the browser boundary guide](../../../docs/practice/games/browser.md).
Use [current editor setup](../../../docs/editors.md) when the task includes editing tools.

Choose from the user's requirements and existing project, not a reference's
fixed defaults. Establish actual versions/dependencies and a minimal host probe,
then connect the game's authoritative core. Respect installation/deployment
permissions and retain asset/dependency notices. A planned route calls for
implementation and verification, not silent fallback to a terminal game.

Separate core build, host build, real input/rendering, deployment and device
performance evidence. Report concrete blockers and the next useful step.
