# 同じ一手で遊び、記録し、置き場所を調べる

たとえば「右回転を押し、Spaceで落とす」という入力を渡すと、盤面が変わり、
回転音・固定音・行消しの通知が順番に返ります。実ウィンドウ、画面を開かない
方策、リプレイは同じ更新関数へ入力を渡します。描画側は返された状態を
表示用の値に変えて描き、音の通知に対応する音源を再生します。

## 受付と更新は別の規則を持たない

`PureFall.Core.gameStep`は現行alphaの`Step Game TickInput [Cue]`です。
`Machine PureFall`はその辞書を返します。`Arena.admit`は参加者と操作数だけを
検査し、元の`TickInput`を返します。`Arena.play`が元のStepを一回呼びます。
衝突、得点、固定の規則を受付側へ書き直していません。

`Observation`には盤面、現在の姿勢、次の5個、ホールド、現在の表示値だけが
あります。乱数状態、未公開の袋の残りはありません。`greedyPolicy`の引数は
この観察履歴です。Haskellの型は、隠しクロージャーやunsafe IOまで禁じる
情報流の証明にはなりません。付属方策は観察値だけを読む実装であり、
隠し乱数状態だけ変えたテストでも同じ選択を返します。

## 描画の間に押されたキーを残す

`FrameInput`はOSで観測した押下と長押しです。hostは`getKeyPressed`の列を
空になるまで取り出し、その順にメニュー操作とゲーム操作を受け付けます。
`isKeyDown`は長押しだけに使います。描画の間に押して離したキーを、
現在押されているかだけで取り逃さないためです。`Session.advanceFrame`は
`FrameMicros`を受け取り、未処理の押下列と時刻の端数を保持します。
1刻みは1,000,000 debt単位、1マイクロ秒は60単位です。`TickNo`は経過刻み、
`TickSpan`は待ち時間です。得点や行数とは別の型になっています。

描画が速く、まだ1刻みに達していなければキーを残します。描画が遅れて
3刻み進む場合、押下は最初の刻みに一度渡し、長押しは3刻みとも渡します。
通常の長押し移動とキー押下による横移動を重ねて二重に動かしません。
停止境界の優先順、32操作ごとの分割、焦点を失った時の時間は仕様書に
定義し、シナリオテストで照合しています。

Yampaは入れていません。現在のalphaはFRPを必須にせず、このゲームでは
シリアライズできる整数カウンターと入力待ちが必要な時間を直接表します。
FreeモナドやECSも、この作品の規則を表すためには追加していません。

## 表示と保存の境界

`PureFall.View.RenderModel`はセルの役割、数値、次ピース、時間、調査候補を
揃えます。rendererは`Game`を受け取りません。通常画面に調査候補を投影して
しまった初回の不具合は、実画面の点検で発見し、通常画面には`StudyCell`を
返さない回帰テストを追加しました。

`Game`、`Board`、`Settings`、`Session`の不変条件に関わるレコード名は
公開しません。`Read Board`と`Read Settings`も検証を通り、`Read Game`は
ありません。公開APIだけを読み込む攻撃用クライアント4件が、意図した
フィールド・コンストラクター・インスタンスの制限でコンパイルに失敗します。

セッションを保存すると、未処理入力と端数、巻き戻し先、操作履歴、現在の
通知も文字列になります。復元時には初期状態から履歴を再生し、現在および
巻き戻し先の状態と一致するかも検査します。巻き戻しは保持した過去状態を
選びます。行消去の写像が一対一になるわけではありません。

hostの保存包みには、調査で選んだ候補と、再生中の残り操作・80ms未満の
待ち時間も入ります。復元時に、本番の移動でその経路が進み、最後のdropで
ちょうど1ピースが固定されることを確認します。現在の姿勢だけを保存して
操作の続きや選択を失う、という復元にはしません。見た目だけの粒子や
音源ハンドルは作り直します。

## APL版・Prolog版と比べる時

| 対象 | このHaskell版 | 比較時に残す違い |
| --- | --- | --- |
| 盤面 | 24行、上4行が非表示 | APL版は22行、上2行が非表示 |
| 回転 | SRSの種類・遷移別の90度kick | Prolog版READMEは独自kick、非SRSと明記 |
| 到達先 | 同じ移動関数で有限グラフを探索、操作列を返す | 各版の回転・姿勢の数え方を合わせてから比較する |
| 行消去 | 満杯行を除き、下にある削除行数だけ各セルを下げる | APLの行圧縮、Prologの関係と、結果と前提を分ける |
| 逆向きの問い | 固定入力を更新し、有限候補を列挙 | Prologの種類・位置を未定にする関係とは異なる |
| 再現 | 一つのStepで入力を再生、セッション復元 | 異なるルール間のトレース一致は主張しない |

APL/Prologに関するこの表は、今回それぞれのREADMEを読んだ範囲です。
相手の全実装を再検証した結果ではありません。

`cabal run pure-fall-study -- --json`は固定盤面、姿勢、操作、結果と出典を
JSONで出します。`comparison/fixtures.json`に今回実行した結果があります。
`--policy`は画面なしで付属方策を動かします。方策の強さ、初心者の理解、
ほかの言語への学習転移や楽しさまで、この実行からは分かりません。
