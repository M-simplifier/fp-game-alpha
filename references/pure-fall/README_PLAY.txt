PURE / FALL — Windows 版

Play.cmd を開くと起動します。Haskell の開発環境は不要です。

左右キーで移動、下キーでソフトドロップ、上キーまたは X で右回転、
Z で左回転、Space でハードドロップ、C または Shift でホールドします。
Esc で一時停止できます。ウィンドウが操作対象から外れた時も一時停止します。

MARATHON は続けられる限りプレイします。40 LINE SPRINT は40ラインを
消すまでの時間、TWO MINUTE は2分間の得点を競います。
PRACTICE では Backspace で直前のピースまで戻り、別の置き方を試せます。
Q で到達先を調べ、PageUp / PageDown で置き場所を選び、Enter で
その操作経路を実行します。もう一度 Q を押すと通常プレイへ戻ります。
置き場所の調査中は落下と固定の時間が止まります。

F1 は操作説明、O は設定、F11 は全画面、M は消音です。設定では左右長押しの
繰り返し速度、音量、BGM を調節できます。移動設定は次の新規ゲームで使います。
F5 はセーブ、F9 は再開。結果画面の R はリプレイ、Enter はやり直しです。
停止中または結果画面で T を押すとタイトルへ戻ります。
記録は %APPDATA%\PureFall に保存します。session.dat がセーブ、settings.dat が
設定とモード別の記録です。

回転は SRS の90度回転と壁蹴りを採用しています。Tスピン、ミニ、
連続の難しい消し方、コンボ、全消しを採点します。
公式テトリス・ガイドラインへの完全な認証を表す作品ではありません。

ソース、厳密なルール、検証範囲は開発用フォルダーの GAME-SPEC.md と
docs/VERIFICATION.md を参照してください。
