# Red Dune source provenance

The MIT colony core and procedural command-room presentation originated in
the Red Dune implementation selected at foundation commit
`e2b57188b7f092eb9f840f451ac48586f47617d9`. The current source extends that core
with campaign, content, policies, transport, construction and durable native/HTTP
hosts. Original copyright remains in LICENSE; publication/provenance.json records
the inherited source commit and original digests separately from current bytes.

The old whole implementation and comparison scaffolding are available in Git
history. Only the current implementation is shipped. Existing save tags,
ruleset identifiers, environment variables and native save locations remain
compatible with the earlier folder named red-dune-live.
