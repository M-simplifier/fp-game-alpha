# Red Dune — 赤い土地に、暮らしをつくる

`Red Dune.exe` を開くと、40人の開拓を始められます。ブラウザや開発環境は
起動に不要です。最初は一時停止。地図の井戸・農場・厨房を選び、
「水を汲み始める」「作物を育て始める」「料理を作り始める」で動かしてください。
必要な班と配送が三交代に配置され、実際に働き、材料を運びます。

地図の施設を選ぶと、材料、作業、班の配置を確認できます。配送タブでは
配給所・農場・厨房へ運ぶ量と配送の有効／停止を調整します。厨房が故障すると
時間が止まるので、保守班と部品の配送を確認してから再開してください。
食料を作るだけでは足りません。運び、住民が食べ、備蓄を保つところまで続きます。

「食事の場」で場所を選ぶと、つなぐ道路と合計費用を確認できます。
確定すると工事と食料の配送が始まり、勤務していない住民が現地の料理を食べます。
食事の場は1か所で、確定後の移設・取消はできません。食料がない時は通常の配給を使います。
「周りを飾る」から敷石・席・鉢・灯りを並べ、自分の場所にできます。飾りは保存され、
「片づける」で並べ直せます。飾りによる生産や食事への加算はありません。

建設・配送・班のタブでは、施設の増設や運ぶ量、三交代の担当を調整できます。
新しい生産施設は、道路・班・材料と出荷の配送をつないで稼働させます。
通常の工事中の施設は取り消せます。

「遊び方」またはF1から、操作・水と食料・配送・班・建設・食事の場・保存の7章を
いつでも読めます。施設やタブの「見方」は、その画面に合う章を開きます。
読む間は時間が止まり、閉じると選択や配置の続きに戻ります。
短い案内は、その時の状況に合うものだけ表示します。「短い案内：OFF」で消せます。
一度読んだ案内は次回起動でも繰り返しません。「案内をもう一度」で表示を戻せます。
保存から再開する時は、井戸・農場・厨房の開始案内を繰り返しません。
この設定は街の保存とは別に記録します。設定が読めなくても正常な街の保存は開けます。

| 操作 | 内容 |
| --- | --- |
| Space | 一時停止／再開 |
| 1・2・3・4 | 1倍・2倍・4倍・8倍 |
| WASD・ホイール | 地図の移動・拡大縮小 |
| Q・E・F | 回転・最初の視点 |
| R | 建設予定の回転 |
| F1 | 今の画面に合う遊び方を開く／閉じる |
| Esc | 遊び方、または選択・建設予定・確認画面を閉じる |
| F5・F9 | 保存・読み込み |

定住は66時間、復旧は42時間の開拓です。実際のプレイ時間は速度設定、
処理時間や判断のための停止で変わります。
ウィンドウを離れると一時停止し、戻ってから再開します。

変更した進行は約30秒ごとと終了時に保存します。保存先は
`%LOCALAPPDATA%\RedDune\saves`。読み込みは、内容の確認後、新しい履歴として
一時停止で再開します。選んだ保存は残ります。読み込めない保存があっても、
ほかの正常な保存を選べます。Linux版の保存先とは別です。

保存先を変更する場合は、`RED_DUNE_NATIVE_STORE` または
`Red Dune.exe --store "保存フォルダー"` を使えます。
