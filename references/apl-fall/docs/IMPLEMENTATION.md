# APLで判定・操作・観察を共用する

盤面を一つ渡すと、ある種類のピースについて「どの向きの、どの位置が空いているか」という1300要素のBoolean配列を作ります。プレイでは現在位置の要素を読み、観察画面では同じ配列を四枚に分けて表示します。規則は`apl/core.apl`、到達可能性は`apl/inspect.apl`、画面と実行ループは`apl/game.apl`にあります。

## 姿勢と四セルの対応

| 配列 | 形状と意味 |
| --- | --- |
| `Board` | 22×10。0は空、1〜7は固定セルの種類／色 |
| `Offsets` | 7×4×4×2。[種類, 向き, 四セル, 行／列] |
| `Poses` | 1300×3。[向き, 基準行, 基準列] |
| `Foot` | 7×1300×4。各姿勢が占有する四セルの線形索引 |
| `Field` | 1300。現種類がその姿勢に収まるか |
| `Actions` | 5×1300。左・右・下・右回転・左回転の移動先索引 |
| `Reachable` / `Supported` | 1300。現在姿勢から到達できるか／そのうち下へ進めないか |
| `Parents` / `ParentActions` | 1300。最初に到達した直前姿勢と操作 |
| 描画行列 | N×9。図形種別、座標・寸法、RGBA |

基準行は−3〜21の25通り、基準列は−3〜9の13通りです。向きを先頭軸として、`pose = 325×orientation + 13×(row+3) + column+3`で平らに並べます。範囲内に、盤内の四セルを持つ全配置が含まれます。

Iは4×4、Oは2×2、他は3×3のBoolean小行列で定義します。`⌽⍉mask`で時計回りに回し、各向きの四セル座標へ変換します。候補全体の行と四セルの行を外積和で足し、列も同様に足して盤面索引を生成します。占有セルだけを調べるため、空白の余白が盤外に出ても排除しません。

盤内索引は0〜219、盤外の占有セルは220です。`extended←(,Board),1`として、番兵だけを必ず塞ぎます。判定の本体は次の二行です。

```apl
extended←(,board),1
field←∧/0=extended[Foot[type;;]]
```

姿勢ごとの衝突関数を繰り返し呼んだ結果を最後に配列へ詰める方式ではありません。候補軸×四セル軸を先に生成し、gatherと縮約で候補全体を求めます。現在・ゴースト・選択着地点の描画も`Foot`の同じ四セルを読みます。

## 落下と操作

`DropDistance`は、向きと基準列を固定して現在行以降の`Field`を取り出します。末尾に0を付け、`(+/∧\slice,0)-1`で下まで連続して合法な距離を返します。途中に0があれば、その下の1は数えません。ゴーストとハードドロップはこの同じ距離を使います。

`BuildActions`は、すべての姿勢からの移動先を同じ姿勢軸で作ります。不合法な操作は自分自身を指します。回転は次の順番で最初に合法になった候補一つを選びます。単位は`(基準行の変化, 基準列の変化)`です。

```text
(0,0), (0,-1), (0,+1), (-1,0), (0,-2), (0,+2), (-2,0)
```

これは種類別の標準SRSではありません。ゲームの`MoveAction`も、探索も、この優先順で確定した`Actions`を使います。盤面または種類が変わる時に`Field`と`Actions`を作り直し、移動ごとには再計算しません。

## 固定した盤面での探索

`ReachFrom`は現在姿勢一つから始めます。現在の前線から五操作の移動先をgatherし、未到達の索引へBooleanをscatterします。新しく到達した点だけを次の前線にし、新しい点がなくなれば終了します。各点の最初の親と操作も保存します。密な隣接行列は作りません。

`Supported`は到達可能で、下操作が自分を指す姿勢です。`Witness`で親を遡り、選択点への操作列を得ます。観察モードの再生は5刻みごとに一操作をゲームの`MoveAction`へ渡します。選択を変えた時は前の再生を止め、探索を始めた姿勢へ戻します。

この探索は盤面を固定し、重力・猶予・時間制限を除いたものです。実時間でその経路を入力できることや、最適な積み方を証明しません。Oのように対称な形も向き番号を保持するので、姿勢数には幾何学的に同じ配置が含まれます。

## 固定、行消去、得点

固定では`Foot[Type;Pose;]`の四セルに種類番号を書きます。満杯の行は`∧/Board≠0`で求めます。残る行を`(~full)⌿Board`で第一軸に沿って圧縮し、消えた数だけゼロ行を上に加えます。残存行の順序を保ち、個々のセルを落とすループはありません。

固定直後の満杯行マスクは`ClearedMask`、件数は`LastClear`に保持します。元の行内容は保存しません。現在の演出は消去件数の短い文字表示で、消去前の行を復元する演出や履歴ではありません。

1〜4行の同時消去は100・300・500・800点に、その時のレベルを掛けます。ソフトドロップは成功した一セルにつき1点、ハードドロップは一セルにつき2点です。レベルは`1+⌊Lines÷10`です。

固定・行消去の後も上2行に占有セルがあるか、次の出現姿勢が不合法ならゲームオーバーにします。通常の出現基準位置は行1・列3で、一部のセルを隠れた領域に残しながら、最初の画面からピースが見えます。

## 入力と時間

ゲーム更新は1/60秒の固定刻みです。フレームからの経過時間は0〜0.1秒に制限し、1描画につき最大6回だけ更新します。長い停止で失った時間を無制限に追い掛けません。低速時にはゲーム時間が実時間より遅れます。

押下の縁は描画間で保持し、最初の更新だけで消費します。横移動は最初の一歩の後、10刻み待ち、3刻みごとに繰り返します。短く押して既に離された左右・下キーの縁も一歩として扱います。同時の左右は相殺します。下は3刻みごとに一セル、重力は`max(3, floor(48×0.82^(Level−1)))`刻みごとに一セルです。

接地から30刻み、約0.5秒で固定します。**既に接地している時の、成功した横移動または回転だけ**が猶予を戻し、その予算は一つのピースにつき15回です。下降、空中での移動、失敗した操作は予算を使いません。上限後も合法な移動はできますが、固定までの時計は戻りません。

同じ更新内では、再開始・見本・観察／ポーズ、保持、右回転、左回転、横移動、ハードドロップ、ソフトドロップ、重力、固定待ちの順に扱います。入力順序を交換可能とはみなしません。

## 乱数と再現

乱数はPark–Millerの整数状態`Seed←2147483647|16807×Seed`です。7種類の配列をFisher–Yatesで並べ替え、袋をキューへ追加します。APL処理系の暗黙の乱数状態は使いません。

`NewGame`へ渡す種は`1+2147483646|⌊|seed`へ正規化します。通常起動の`InitialSeed`は時計から一度だけ求め、再開始では同じ値を使います。テスト用の`tests/fixed-seed.apl`は314159を設定します。配列・整数状態・更新順が同じなら、900刻みの入力記録で盤面・キュー・種・得点が一致することを検査しています。
