# 研究の経緯と、現在へ持ち帰るもの

いまの `Step` や描画設計は、最初から決まっていた共通エンジンではない。
異なる作品を作り、共通に扱えたことと、同じ扱いにすると壊れたことを調べて
少しずつ選んできた。この棚では、現在の実装だけでは見えにくい経緯を読む。
過去の予定を、現在の開発計画として再開するための一覧ではない。

| 知りたいこと | 読む資料 |
| --- | --- |
| 作品ごとの時計や失敗を残したまま、履歴と解析を共有できるか | [遷移・Arenaの成立と反例](transitions-and-arenas.md) |
| 型、SMT、精密化型、モデル検査は、どの主張を確かめたか | [形式手法の結果と失敗](formal-methods.md) |
| 変更して遊ぶまでの待ち時間を、何を変えて減らしたか | [反復制作と実行環境](iteration-and-platforms.md) |
| 大きな物理試験や3D作品から、何を引き継ぎ、何を保証しないか | [初期作品と終了した実験](earlier-prototypes.md) |

研究全体は[研究案内](../README.md)、主題別の入口は[目録](../catalog.json)、
調査した資料の範囲は[収録範囲](../coverage.md)にある。
現在の実行手順は、各作品と[検証ガイド](../../docs/verification.md)を優先する。
ここで引用する過去の実行結果は、2026-11-06に再実行した結果ではない。
